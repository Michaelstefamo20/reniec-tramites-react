# RENIEC Trámites+ (prototipo)

Prototipo responsive en React + Vite (HTML, CSS y JavaScript).

## Ejecutar
1. Instala Node.js 18 o superior.
2. En esta carpeta: `npm install`
3. `npm run dev` y abre la dirección que muestra (http://localhost:5173).

## Estructura
- `src/styles.css`: estilos y colores (`--navy` guinda, `--gold` dorado).
- `src/data.js`: datos de ejemplo (trámites, familia, agencias, textos del asistente).
- `src/utils.js`: análisis de fotos y documentos, y cálculo de demanda.
- `src/components/`: Shell (menú), Inicio, Nuevo, Mis, Familia, Ayuda, Demanda, CitaConjunta, Assistant.
- `src/assets/logo.png`: logo de RENIEC.
